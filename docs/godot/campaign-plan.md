# Campaign migration contract

Browser source remains authoritative and untouched. Starting point `af85238`; existing M1 checks remain regression references. This pass ports Breach and Blackout plus the outstanding Control Room systems and campaign shell. Do not call audiovisual/native-platform differences exact rendering parity.

## Agreed ownership/interfaces before delegation

- Same two meters/tile, `(x,y)->(2x,0,2y)`, yaw-only camera, 1.4m eye, world bit1/player2/enemy4. Shootable device bit8; queries include areas, exclude player, and retain positive center-depth/nearest-wall checks.
- Root owns `main.gd`, `player.gd`, new `mission_data.gd` and `campaign_state.gd`, plus integration/UI/docs. Root main exposes `mission_index`, `mission` Dictionary (`id,title,map,spawn,panel,core,exit,bots,objective` in native units), `enemies:Array`, legacy `guard` alias, `room`, `player`, `active`, `elapsed`, `alarm_triggered`, `alarm_active`, `panel_disabled`, `power_restored`, `core_collected`, `shots,hits,health,ammo`, `first_route`, `session`, `systems`; callbacks `has_los`, `trigger_alarm`, `damage_player`, `register_event`, `announce`, `spawn_enemy(spec)`.
- Geometry/enemy owner only `room.gd`,`armored_guard.gd`. Room `build(config:Dictionary={})` defaults M1 Control Room, uses config map/panel/core/exit/mission id; rebuild is a new room instance. APIs existing gate/panel/core setters plus `set_bulkhead(closed)`, `set_service_power(enabled)`, `set_service_lamp(enabled)`, `set_camera_enabled(enabled)`, `set_power_restored(enabled)`; all geometry/device visuals can be original primitives, only walls/gate/bulkhead collide. Guard `setup(controller,spawn,spec:Dictionary={})`, fields role/id/speed/damage/attack_range; role armored/scout/turret, hp3/2/3, velocities .58/1.25/0 tile/sec, damage18/8/10, ranges1.15/.95/4.5 tile. Scout windup .55, turret cooldown1.5. Guard patrol only `is_guard`; investigation target supplied `investigation` Dictionary native `{position,left}` via systems, grid BFS using current map+door. Guard detection only control guard, same cone/timers. Root handles reinforcement.
- Systems owner only `encounter_systems.gd` (+ optional `native_audio.gd`). RefCounted systems `setup(main)`, `reset()`, `update(delta)`, `interact()->bool`, `shootable_hit(id:String)->bool`, `prompt()->String`, `objects` via room visuals, state `power_routed,overloaded,intel,secret,door_open,camera_disabled,camera_alert,lamp_broken,investigation`; `on_shot()` starts investigation. `reset` also creates camera/lamp Area3D bit8 in a child Node3D `Devices` attached to root; each target has `device_id` metadata and `target_center` native position; geometry owner owns visual meshes. `finish(won)` delegates successful journal/consequence commit to session; root sole session commit owner (systems must not commit). Camera data native14.6,0,11, power13,0,15, overload17,0,15, intel17,0,11, switch15,0,15, bulkheadtile(8,6), cache15,0,17, lamp7,0,11.6. Interaction1.6m, LOS, nearest device; original panel1.7m handledroot after systems. Full door actor obstruction2tile grid bounds with .4m tolerance, overload8m/3seconds+LOS, cache+25once, intelalarms unlesspanel. Camera sweep and cone .91, range12m, detect1.25s, decay2/s, power/panel block. Sound optional original synthesized local, independent file.
- Session interface root `session.decisions` Dictionary security_disabled/alarm_raised/intel/secret, `session.journal:Array[String]`, `session.note(text)` provisional per attempt, `session.commit(mission,state,won)` only on success, `session.new_campaign()`, `session.begin_attempt()`. Rank formula same browser. Root snapshot state for commit includes `panel_disabled,alarm_triggered,intel,secret,elapsed,shots,hits,health`.
- UI root owns title/briefings/play/result/continue/retry/summary, paused settings/journal/abandon-confirm, saved native preferences, onboarding, CSV. All timers only advance unpaused in physics. Native F5 retry supported without changing mission or prior committed decisions.
- Independent reviewer owns `godot/tests/campaign_test.gd` and review report; may recommend updates to M1 assertions made obsolete by intentional campaign UI changes, never weaken mechanic checks.
